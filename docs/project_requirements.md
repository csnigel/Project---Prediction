# Coursework requirements

## Individual phase

The individual submission required predictions for the nine targets in `test_individual.csv` and a comparison among:

- a naive per-target training mean;
- at least one non-deep-learning model;
- at least one deep-learning model.

Model selection had to use an appropriate validation procedure, report comparative results, justify preprocessing and hyperparameters, and account for uncertainty across folds.

## Group phase

The final report required:

- a concise problem introduction and result summary;
- a description of every member's individual approach;
- a shared, objective comparison of the individual and newly developed group approaches;
- discussion of whether the individual leaderboard affected group selection;
- limitations, conclusions, and credible future work;
- a complete code appendix.

The repository presents these requirements as project context rather than as grading material.
